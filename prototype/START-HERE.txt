My Hoval Focus | Calendar and Xurrent deadlines

For a laptop that blocks the unsigned companion, use the existing Ticket Asystent 1.5. In Focus choose Sync with Xurrent > Download change package. Save the JSON beside the assistant, run its usual launcher, choose option 2, select the package, and review current and proposed dates. The package includes one internal scheduling note for each request. After execution import a fresh ticket export into Focus. Exporting a package keeps drafts pending. Use the original downloaded file if retrying the identical batch.

1. Open My-Hoval-Focus.html in desktop Edge. Explore the sample Week and Month calendars.
2. For real data, use Sources > Import tickets and select a recent JSON export from Ticket Asystent with request details, desired_completion_at, account and user.id.
3. Drag a ticket to a day, or click it to choose a date. The change is a local draft. Existing deadlines keep their local time. New deadlines use 16:00 local time. Project milestones are personal and can be added and edited below the calendar.
4. To enable sending, copy Focus-Sync.ps1 and Start-Focus-Sync.cmd to your existing Ticket Asystent folder containing Token.ps1. Start Start-Focus-Sync.cmd there. It uses the same Windows account and saved Xurrent token as Ticket Asystent. Enter the account ID from your export. Leave the window open while syncing.
5. Click Sync with Xurrent, review the old and new deadlines, then Send. When Edge asks for a folder, choose the same Ticket Asystent folder. The helper reads each assigned request, compares the current deadline, patches desired_completion_at only, and reads the result back. The browser reports verified results per request. If a result is uncertain, import a current export before retrying. Verified matching deadlines clear the draft. No further upload is needed for the normal Send operation.
6. Stop the helper by closing its window. The HTML can still plan offline. The browser and Windows must permit local folder access and the script. Results and any pending request files in the assistant folder can contain private ticket references. Store them with the user's private exports.
7. This connector handles the numeric Requests API IDs supported by the exporter. C-prefixed workflow IDs need a separate verified mapping. Add real milestones in My workspace. Source notes, the private My next action text, project milestones and daily priorities are not sent to Xurrent.
