# Product and design brief

Owner's bar: modern premium application, excellent typography/spacing, useful daily overview, responsive desktop behavior and minimal manual configuration. He wants colleagues and management to see a polished working tool. Do not promise universal acclaim.

English UI; working name My Hoval Focus. Tagline: Your priorities. Your next steps. One place.

Existing visual direction: restrained Hoval red accent (214,0,28), dark navy (25,35,49), light gray workspace (245,247,250), white content cards. Existing Projects uses a left sidebar, project summary, three metrics, searchable task list and detail pane. This implementation did not meet the owner's expectations; treat it as a prototype, not a design gold standard.

Planned surfaces: Overview, Projects, Inbox, My Sources. Prefer real tasks, actionable information and explicit freshness. Never add fake progress, inferred priority or unsupported AI summaries to make a screenshot impressive. Blank source status is missing information. Preserve long task descriptions/comments and keyboard access.

For WWW: choose responsive layouts based on content, with useful breakpoints, density, task selection, loading/error/empty states and clear source freshness. Show minimal functionality with real authenticated data before investing in detailed styling. Do not build another polished mockup that cannot be deployed.

Raw historical previews contained workbook content and are intentionally not in Git. Layout source is retained. Original previews remain in the originating conversation's private files.
