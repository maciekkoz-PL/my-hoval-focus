# Polecenie do wklejenia innemu AI

Kontynuuj projekt My Hoval Focus w tym repozytorium. Najpierw przeczytaj AGENTS.md, README.md, docs/STATE.md, docs/NEXT_STEPS.md i docs/KNOWN_ISSUES.md. Nie zaczynaj od nowa i nie pytaj mnie o rzeczy opisane w plikach.

Mamy działający ręczny import 41 zadań z Excela przez Office Script i Power Automate do SharePoint. Powtórny import aktualizuje te same rekordy. Ekran Projects działa jako prototyp Power Apps, ale wygląd i skalowanie nie spełniają oczekiwań. Rozważamy własny interfejs WWW/SPFx, zachowując istniejący backend Power Automate + SharePoint.

Najpierw sprawdźmy możliwość wdrożenia i odczytu prawdziwej listy z poziomu aplikacji WWW przy firmowym logowaniu. Nie buduj kolejnej dużej makiety przed potwierdzeniem tej drogi. Nie zakładaj, że mam uprawnienia katalogu aplikacji SPFx lub rejestracji Entra. Komputer firmowy ma ograniczenia; nie obchodź ich.

Aplikacja ma być po angielsku. Rozmawiaj ze mną po polsku. Chcę bardzo dobry wygląd, responsywność i jak najmniej ręcznego klikania. Odróżniaj działający kod od planów. Po pracy zaktualizuj dokumentację stanu i następnych kroków, aby kolejne AI mogło kontynuować.

Repozytorium jest prywatne: potrzebujesz mojego autoryzowanego dostępu do niego. Sam link nie przyznaje uprawnień. Nie modyfikuj osobnego projektu tickety-ai.
